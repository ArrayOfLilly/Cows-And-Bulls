## Data Collected & Purposes

The App does not collect, store, or transmit personal data. Gameplay-related data (e.g., settings, game state) is stored locally on the user’s device only.

Export/Import: The App allows users to export and import gameplay-related data in JSON format to a user-chosen location. Exported files are not automatically transmitted to the developer.

## Legal Basis

No personal data processing occurs, as data remains locally on the device.

## Data Sharing and Processors

The App does not share data with third parties and does not use data processors. If the user chooses a third-party storage location (e.g., cloud storage), the chosen provider’s own policies apply.

## Third-Party Services

The App currently does not integrate third-party services that involve data processing. If this changes, we will update this Policy accordingly.

## Security

The App stores gameplay-related data locally and performs only the file operations necessary for functionality (e.g., export/import). Absolute security cannot be guaranteed.

## Data Retention

Data stored on the device is removed when the App is uninstalled. Exported JSON files are retained and deleted by the user at the chosen storage location. Data imported into the App is used locally on the device.

## User Rights

Since no personal data is processed, GDPR-related rights typically do not apply. If you believe personal data is involved, please contact us using the details in Controller.

## Children’s Privacy

The App does not collect personal data and is not intended to collect data from children.

## Open Source & Transparency

The App is open source. The source code is publicly available and auditable, allowing anyone to verify filesystem operations and how locally stored data is handled.

Repository: https://github.com/ArrayOfLilly/Cows-And-Bulls
